PROJECT NOTES

How Log Sentinel works.

A simple log parser and rule-based investigation aid.

01

Parse

Recognizes supported key-value events, common OpenSSH authentication messages, and JSON event records. Lines it cannot understand remain visible as unparsed.

02

Group

Uses JavaScript objects to group recognized events by source IP and count failed and successful authentication attempts.

03

Flag

Compares each IP's failed-login count against your threshold. A flag means “review this source,” not “confirmed attacker.”

04

Report

Builds charts and tables from the parsed data and lets you export event and IP summaries to CSV.

ⓘ

Data handling: Log content is processed in your browser tab and isn't uploaded. The site stores no raw logs in localStorage. Use synthetic or properly authorized logs only.

How to use Log Sentinel

Analyze sample or authorized authentication logs. The parser recognizes a few common formats and shows unrecognized lines rather than silently dropping them.

  • Use Analyze logs to paste or upload a local file.
  • Set the failure threshold in Analysis settings.
  • Review flagged IPs and the surrounding events before drawing conclusions.
  • Export a CSV summary for further review.

This is a learning tool. It does not monitor a live network or prove an attack from login counts alone.
